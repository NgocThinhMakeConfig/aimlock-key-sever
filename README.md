# AIMLOCK KEY SERVER

Server key cho app AIMLOCK TARGET.

## API Endpoints

- GET / — Health check
- POST /api/verify — Xác thực key
- POST /api/heartbeat — Kiểm tra định kỳ
- POST /api/admin/create — Tạo key
- POST /api/admin/list — Danh sách keys
- POST /api/admin/set-status — Đổi trạng thái
- POST /api/admin/delete — Xóa key
- POST /api/admin/stats — Thống kê
